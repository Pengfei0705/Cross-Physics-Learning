## 🔬 Overview

Can deep learning learn a mapping **between different physical systems**?

This repository accompanies the project:

> **Can Deep Learning Achieve Cross-Physics Mapping?**

Instead of learning the solution operator of a single governing equation, we investigate whether neural networks—particularly **neural operators**—can learn a transformation between the solution spaces of fundamentally different physical systems.

The central task considered here is

$$
\boxed{
\text{Diffusion Field}
\quad \xrightarrow{\\mathcal{G}_{\theta}\} \quad
\text{Wave Field}
}
$$

where both fields arise from the **same latent physical scene**, including geometry, defects, excitation configuration, and characteristic physical scales.

The project compares seven deep-learning architectures for reconstructing a wave-dominated field from a diffusion-dominated observation.

---

## 💡 Core Idea

Conventional scientific machine learning typically learns

$$
\text{input parameters}
\rightarrow
\text{solution of one PDE}.
$$

Cross-Physics Mapping instead asks whether we can learn

$$
\text{solution of Physics A}
\rightarrow
\text{solution of Physics B}.
$$

Let

$$
u(\mathbf{x},t)\in\mathcal{F}_A
$$

denote the field generated by the source physics and

$$
v(\mathbf{x},t)\in\mathcal{F}_B
$$

the field generated by the target physics.

We seek a nonlinear operator

$$
\boxed{
\mathcal{G}_{A\rightarrow B}:
\mathcal{F}_A\rightarrow\mathcal{F}_B
}
$$

such that

```math
v(\mathbf{x},t)
\approx
\mathcal{G}_{\theta}[u](\mathbf{x},t).
```

This is fundamentally different from a local pixel-to-pixel transformation because the relationship between the two fields can be highly **nonlocal in space and time**.

---

## ⚛️ Physical Motivation

### Source Physics: Diffusion

The source-domain field satisfies a heterogeneous diffusion equation

```math
\frac{\partial u}{\partial t}
=
\nabla\cdot
\left[
\alpha(\mathbf{x})\nabla u
\right]
+s_d.
```

Diffusion progressively suppresses high-spatial-frequency information and smooths the observed field.

### Target Physics: Wave Propagation

The target-domain field follows a heterogeneous wave equation

```math
\frac{\partial^2v}{\partial t^2}
=
\nabla\cdot
\left[
c^2(\mathbf{x})\nabla v
\right]
+s_w.
```

Unlike diffusion, wave propagation retains features including propagation fronts, arrival times, reflections, interference, and defect-induced scattering.

The mapping is therefore highly nontrivial:

```text
Diffusion
    │
    │  smooth / dissipative
    ▼
Latent Physical Scene
    │
    │  geometry + defects + excitation + scale
    ▼
Wave
    │
    └── propagation / reflection / scattering
```

---

## 🌉 Cross-Physics Representation

The conceptual mapping can be expressed as

```math
\boxed{
\mathcal{G}_{A\rightarrow B}
=
\Phi_B
\circ
\mathcal{M}_{A\rightarrow B}
\circ
\Phi_A^{-1}
}
```

where the two physical fields are regarded as different representations of a compatible latent physical structure.

The two systems **do not need to obey the same governing equation**.

Instead, successful cross-physics learning relies on constructing physically compatible paired observations.

---

## 📐 Dimensionless Physical Matching

To avoid arbitrarily pairing unrelated diffusion and wave fields, the dataset is constructed using comparable characteristic propagation scales.

### Diffusion

For an observation interval $t_0$,

$$
\ell_d\sim\sqrt{\alpha t_0},
$$

with Fourier number

$$
Fo=\frac{\alpha t_0}{L^2}.
$$

### Wave

The corresponding wave propagation distance is

$$
\ell_w=ct_0,
$$

with dimensionless propagation scale

$$
\Lambda=\frac{ct_0}{L}.
$$

We impose the similarity condition

$$
\boxed{
Fo=\Lambda^2
}
$$

which gives

$$
\boxed{
\alpha=c^2t_0.
}
$$

> **Important:** this condition is used as a **data-generation constraint**. It is not an analytical identity between the parabolic diffusion equation and the hyperbolic wave equation.

Its purpose is to ensure that both physical systems probe comparable spatial scales over the same observation window.

## 🗃️ Dataset

The Cross-Physics Mapping dataset contains paired diffusion and wave simulations generated from common latent scenes.

Current dataset configuration:

| Property                      | Value                        |
| ----------------------------- | ---------------------------- |
| Number of paired realizations | 1,000                        |
| Observation size              | $501\times200$             |
| Source domain                 | Diffusion                    |
| Target domain                 | Wave propagation             |
| Pairing                       | Shared latent physical scene |
| Physical matching             | Dimensionless similarity     |
| Task                          | Diffusion → Wave             |

Each sample contains a pair

$$
\boxed{
(u_i,v_i)
}
$$

generated from the same structural and excitation configuration.

### Dataset Generation Pipeline

```text
┌────────────────────────┐
│   1. Latent Scene      │
│ Geometry / Defects     │
└───────────┬────────────┘
            │
            ▼
┌────────────────────────┐
│   2. Excitation        │
│ Pulse / Chirp /        │
│ Gaussian / Lock-in     │
└───────────┬────────────┘
            │
       ┌────┴────┐
       ▼         ▼
┌────────────┐ ┌────────────┐
│ Diffusion  │ │   Wave     │
│   Solver   │ │   Solver   │
└─────┬──────┘ └──────┬─────┘
      │               │
      ▼               ▼
┌─────────────────────────────┐
│ Common Observation Grid     │
│         501 × 200           │
└─────────────────────────────┘
```

The dataset includes multiple excitation configurations, such as:

* plane excitation,
* Gaussian excitation,
* asymmetric Gaussian excitation,
* localized Gaussian excitation,
* short-pulse excitation,
* chirp excitation,
* lock-in-style excitation.

Different defect geometries and structural configurations are used to test whether the learned operator generalizes beyond individual excitation or defect signatures.

## 🧠 Models

Seven architectures are evaluated under the same cross-physics task.

| Model        | Description                                                                     |
| ------------ | ------------------------------------------------------------------------------- |
| **ResUNet**  | Residual convolutional encoder-decoder baseline                                 |
| **U-NO**     | U-shaped multiscale neural operator with global spectral mixing                 |
| **FNO**      | Fourier Neural Operator for global spectral operator learning                   |
| **WNO**      | Wavelet Neural Operator using localized multiresolution representations         |
| **LNO**      | Latent Neural Operator learning the transformation in a compressed latent space |
| **GNO**      | Galerkin-style operator with coordinate-aware global mixing                     |
| **DeepONet** | Branch-trunk operator factorization                                             |

These architectures represent different strategies for learning the nonlocal mapping

$$
u(\mathbf{x},t)
\rightarrow
v(\mathbf{x},t).
$$

## 📊 Results

The current comparison shows that neural-operator architectures can substantially outperform the convolutional image-to-image baseline.

| Model    |                       MSE |                    MAE |                   RMSE |   Rel. L2 |        R² |
| -------- | ------------------------: | ---------------------: | ---------------------: | --------: | --------: |
| DeepONet |     $3.25\times10^{10}$   |     $4.51\times10^4$   |     $1.80\times10^5$   |     0.548 |     0.698 |
| FNO      |     $1.66\times10^{10}$   |     $3.23\times10^4$   |     $1.29\times10^5$   |     0.391 |     0.846 |
| ResUNet  |     $3.03\times10^{10}$   |     $4.43\times10^4$   |     $1.74\times10^5$   |     0.528 |     0.719 |
| **U-NO** |$\mathbf 1.02\times10^{10}$| $\mathbf2.18\times10^4$| $\mathbf1.01\times10^5$| **0.307** | **0.905** |
| WNO      |     $1.72\times10^{10}$   |     $3.82\times10^4$   |     $1.31\times10^5$   |     0.398 |     0.841 |
| GNO      |     $1.71\times10^{10}$   |     $3.57\times10^4$   |     $1.31\times10^5$   |     0.397 |     0.841 |
| LNO      |     $1.44\times10^{10}$   |     $2.69\times10^4$   |     $1.20\times10^5$   |     0.365 |     0.866 |

### Main Observation

Among the tested architectures, **U-NO provides the strongest overall performance**, achieving

$$
R^2=0.905
$$

and

$$
\mathrm{Relative}\ L_2=0.307.
$$

The results suggest that global and multiscale operator learning is particularly useful for cross-physics reconstruction, where the relationship between input and output cannot be represented adequately by local transformations alone.

## 🔍 Representative Test Cases

The models are evaluated across substantially different physical configurations.

### 1. Short Pulse + Square-Hole Defect

Tests whether the network can reconstruct sharp wavefronts, reflections, and defect-scattered components from a strongly smoothed diffusion observation.

### 2. Chirp Excitation + Defect-Free Plate

Tests whether the learned mapping remains valid without characteristic defect signatures.

### 3. Centered Gaussian Chirp

Evaluates cross-physics reconstruction under spatially nonuniform excitation and localized high-amplitude responses.

### 4. Asymmetric Localized Gaussian Excitation

A challenging long-pulse configuration containing complex and nonuniform spatiotemporal structures.

### 5. Multiple Square Defects

Tests long-range propagation, repeated scattering, and interactions between multiple defect-induced responses.

## ⚡ Minimal Inference Example

```python
import torch

from cpm.models import UNO
from cpm.io import load_sample


device = torch.device(
    "cuda" if torch.cuda.is_available() else "cpu"
)

model = UNO.from_checkpoint(
    "checkpoints/uno_best.pt"
).to(device).eval()


diffusion = load_sample(
    "sample.mat",
    key="diffusion"
)

x = torch.from_numpy(
    diffusion
)[None, None].float().to(device)


with torch.no_grad():

    wave_pred = model(x)


print(wave_pred.shape)
```

Expected output:

```text
torch.Size([1, 1, 501, 200])
```
